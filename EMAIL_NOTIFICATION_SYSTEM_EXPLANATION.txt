================================================================================
                     EMAIL NOTIFICATION SYSTEM - HOW IT WORKS
================================================================================

This document explains how the My Film Jobs email notification system works, from 
user interaction to email delivery.

================================================================================
                            SYSTEM OVERVIEW
================================================================================

The email notification system is a comprehensive solution that handles both 
in-app notifications and email delivery. It consists of several interconnected 
components that work together to provide a seamless user experience.

================================================================================
                            ARCHITECTURE
================================================================================

FRONTEND (React Components):
├── NotificationSettings.tsx    # User preference management
├── NotificationCenter.tsx      # Notification display and management
└── Navigation.tsx             # Integration point

BACKEND (Firebase Functions):
├── emailService.ts            # Email sending logic
├── notificationService.ts     # Notification creation and management
└── index.ts                  # Event triggers and HTTP endpoints

DATABASE (Firestore):
├── users/{userId}/notifications/  # User notifications
├── users/{userId}/preferences/    # User notification preferences
└── Various collections for triggers (jobApplications, projects, etc.)

================================================================================
                            HOW IT WORKS - STEP BY STEP
================================================================================

1. USER PREFERENCE MANAGEMENT
================================================================================

When a user opens the notification settings:

a) The NotificationSettings component loads user preferences from Firestore
b) User can toggle different notification types:
   - Email Notifications (on/off)
   - Push Notifications (on/off)
   - Job Application Notifications
   - Project Invitation Notifications
   - Task Assignment Notifications
   - Message Notifications
   - Project Update Notifications
   - Application Status Notifications

c) User can set notification frequency:
   - Immediate: Send notifications right away
   - Daily: Send digest once per day
   - Weekly: Send digest once per week

d) Changes are saved to Firestore in real-time

2. EVENT TRIGGERS
================================================================================

The system monitors various events in your app:

a) Job Application Submitted:
   - Trigger: onDocumentCreated("jobApplications/{applicationId}")
   - Action: Notify job poster about new application
   - Email Template: Professional application notification

b) Project Invitation Sent:
   - Trigger: onDocumentCreated("projectInvitations/{invitationId}")
   - Action: Notify invited user about project invitation
   - Email Template: Project invitation with role details

c) Task Assigned:
   - Trigger: onDocumentCreated("tasks/{taskId}")
   - Action: Notify assignee about new task
   - Email Template: Task assignment with due date

d) New Message:
   - Trigger: onDocumentCreated("conversations/{conversationId}/messages/{messageId}")
   - Action: Notify recipient about new message
   - Email Template: Message preview with sender info

e) Project Updated:
   - Trigger: onDocumentUpdated("Projects/{projectId}")
   - Action: Notify team members about project changes
   - Email Template: Project update summary

f) Application Status Changed:
   - Trigger: onDocumentUpdated("jobApplications/{applicationId}")
   - Action: Notify applicant about status change
   - Email Template: Status update with next steps

3. NOTIFICATION CREATION PROCESS
================================================================================

When an event is triggered:

a) Firebase Function detects the event
b) Function calls NotificationService.createNotification()
c) NotificationService:
   - Creates in-app notification in Firestore
   - Checks user preferences for email notifications
   - If email is enabled, calls EmailService.sendEmail()
   - Uses Handlebars templates to generate email content

4. EMAIL SENDING PROCESS
================================================================================

When an email needs to be sent:

a) EmailService.initialize() is called:
   - Sets up Nodemailer with Gmail SMTP
   - Configures SendGrid as fallback
   - Loads email templates

b) EmailService.sendEmail() is called with:
   - Recipient email address
   - Email template (subject, HTML, text)
   - Template data (user names, project details, etc.)

c) Email template is processed:
   - Handlebars compiles the template
   - Template data is injected
   - HTML and text versions are generated

d) Email is sent:
   - Try SendGrid first (if configured)
   - Fallback to Nodemailer with Gmail SMTP
   - Log success/failure for monitoring

5. EMAIL TEMPLATES
================================================================================

Each notification type has its own email template:

a) Template Structure:
   - Subject line with dynamic data
   - HTML version (styled, professional)
   - Text version (plain text fallback)
   - Handlebars variables for personalization

b) Template Variables:
   - {{userName}}: Recipient's name
   - {{senderName}}: Sender's name
   - {{projectName}}: Project name
   - {{jobTitle}}: Job title
   - {{status}}: Application status
   - {{dueDate}}: Task due date
   - {{message}}: Message content
   - {{dashboardUrl}}: Link to relevant page

c) Template Examples:

Job Application Template:
Subject: "New Application for {{jobTitle}}"
HTML: Professional layout with application details
Text: Plain text version for email clients

Project Invitation Template:
Subject: "You're invited to join {{projectName}}"
HTML: Project details with accept/decline buttons
Text: Simple invitation text

7. CONFIGURATION AND SETUP
================================================================================

Email Configuration:
- Gmail SMTP: smtp.gmail.com:587
- Google Workspace account: iam@myfilmjobs.com
- App password authentication
- Firebase Functions config storage

Firebase Functions Config:
```bash
firebase functions:config:set smtp.host="smtp.gmail.com"
firebase functions:config:set smtp.port="587"
firebase functions:config:set smtp.user="iam@myfilmjobs.com"
firebase functions:config:set smtp.pass="[app-password]"
firebase functions:config:set email.from="iam@myfilmjobs.com"
firebase functions:config:set app.frontend_url="https://myfilmjobs.com"
```
